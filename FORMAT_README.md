Bu repo içindeki `Untitled-1.css` dosyasını daha okunabilir hale getirmek için küçük bir Node.js betiği eklendi.

Kullanım:

1. Terminalde proje köküne gidin (buradaysanız zaten doğru dizindesiniz):

```bash
cd /Users/aibatyr/Documents/SEO
```

2. Betiği çalıştırın:

```bash
node tools/format_css.js
```

3. Çıktı dosyası `Untitled-1.prettified.css` olarak oluşturulur.

Not: Bu basit bir biçimlendiricidir; çok karmaşık edge-case'leri işlemez. İsterseniz `prettier` veya başka bir CSS formatter ile daha sağlam sonuç alabiliriz.
